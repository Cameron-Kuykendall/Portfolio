Sorting Algorithm Visualizer

Sorting Algorithm Visualizer is an interactive web application that demonstrates how classic sorting algorithms work in real time. The visualization dynamically renders arrays as vertical bars and animates the comparisons and swaps performed by algorithms such as Bubble Sort, Selection Sort, and Insertion Sort. Built with modern JavaScript and a responsive front-end interface, the project focuses on translating algorithmic logic into clear visual feedback that helps users intuitively understand how sorting processes operate step-by-step. Key challenges included designing smooth animations, synchronizing algorithm execution with UI updates, and structuring the code so multiple algorithms could be visualized using the same rendering system. This project demonstrates my ability to combine computer science fundamentals with interactive front-end development to create educational and engaging software tools.

AI Agent Projects

This collection of projects explores how AI agents can assist users through intelligent software systems. These applications combine machine learning APIs, secure backend infrastructure, and modern front-end interfaces to create practical tools that solve real-world problems.

These projects highlight my interest in building intelligent systems that combine AI capabilities with secure and scalable software architecture.
