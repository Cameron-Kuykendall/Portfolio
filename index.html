PROJECTS

Counselor Notes

Desktop Website

This secure web platform helps school counselors manage and protect student information in full compliance with FERPA. It features multi-factor authentication (SMS & TOTP), role-based access control, encrypted note storage, and audit logging for every data event. Built with Node.js, Express, and AWS services like DynamoDB and S3, it ensures both privacy and reliability. Key challenges included designing scalable backend infrastructure, implementing secure data flows, and maintaining compliance without sacrificing usability. This project demonstrates my ability to integrate security, performance, and user-centered design in production environments.

Sprutix (Coming soon to app store)

Sprutix is a cross-platform mobile app built with React Native and Expo that helps users identify, track, and care for their plants. It integrates AI features for plant identification, disease detection, and light metering, while offering a pixel-art inspired interface for an engaging user experience. AWS services like DynamoDB and S3 handle secure data storage and image management. Key challenges included optimizing performance across devices, managing cloud integrations, and maintaining responsive, intuitive design. Sprutix showcases my ability to combine functionality, creativity, and technical scalability.
